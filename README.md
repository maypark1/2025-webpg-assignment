## 개발 룰
1. 에셋(이미지, 영상, 소리 등등) 넣으실때 asset 폴더에 넣어주세요. 에셋 같은거 연결할때는 상대 경로나 절대 경로 방식으로 넣어주시면 됩니다.

2. 코드 짤때 CSS는 HTML 파일 안에 쓰지 말고 파일로 따로 짜서 올려주세요.

3. 다른 사람이 만들던거 실수로 건들수도 있기도 해서 모든 개발은 파트별로 브랜치 나눠서 합니다.
   
상대경로와 절대경로 모르시면 [이거](https://idea9329.tistory.com/519)나 [이거](https://velog.io/@zunyange/%EC%83%81%EB%8C%80%EA%B2%BD%EB%A1%9C-%EC%A0%88%EB%8C%80%EA%B2%BD%EB%A1%9C-%ED%91%9C%EA%B8%B0%EB%B2%95) 보고 오시면 됩니다.
